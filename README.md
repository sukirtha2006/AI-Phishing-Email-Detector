# AI-Based Phishing Email Detector

## About the Project
This project uses Machine Learning to classify email messages as potentially phishing or legitimate.

## Features
- Email message analysis
- Phishing email detection
- Legitimate email classification
- Prediction score
- Graphical User Interface
- Security report generation

## Technologies
- Python
- Pandas
- Scikit-learn
- TF-IDF
- Logistic Regression
- Tkinter

## How to Run

1. Install dependencies:
   `py -m pip install -r requirements.txt`

2. Train the model:
   `py train_model.py`

3. Run the application:
   `py main.py`

## Disclaimer
This is an educational prototype. Its predictions may be incorrect and should not be used as the only method of email security verification.
